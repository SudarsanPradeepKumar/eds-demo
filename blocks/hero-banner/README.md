# hero-banner

Custom **hero** block. Purpose: Promotional banner (subscription offer, rewards) with heading, short copy and a single call to action over a decorative background image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 row: cell 1 = decorative background image (optional); cell 2 = heading, paragraph(s), CTA link (link in its own paragraph renders on the right).
