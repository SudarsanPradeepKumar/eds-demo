# form

Custom **form** block. Purpose: Single-column form (registration, contact details, machine/payment selection) with stacked labels, grouped fieldsets, consent checkbox and submit button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: either a link to a spreadsheet JSON form definition (columns Name, Type, Label, Placeholder, Value, Options, Mandatory, Fieldset) plus an optional submit-endpoint link, or one row per field: Label | Type (text, email, tel, password, textarea, select, checkbox, radio, fieldset, heading, plaintext, submit) | Placeholder or comma-separated Options | Required (yes/no); an optional leading single-cell row holds the heading/intro text.
