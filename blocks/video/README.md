# video

Custom **video** block. Purpose: Full content-width 16:9 video player with an optional poster image used as a click-to-play placeholder.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; optional poster picture plus a link to the video (MP4/WebM URL, YouTube, Vimeo, or a player page such as an AEM Dynamic Media /play URL, embedded as a 16:9 iframe); optional caption text.

## Supported variations

No variations.
