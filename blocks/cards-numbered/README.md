# cards-numbered

Custom **cards** block. Purpose: Numbered process/steps list (e.g. sustainability focus areas, subscription steps).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per step; cell 1 = image, cell 2 = heading + paragraph(s), optional subheadings, lists and link. Step numbers and alternating image side come from CSS; authors never number or swap cells..

## Supported variations

No variations.
