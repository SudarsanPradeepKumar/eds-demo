# cards-feature

Custom **cards** block. Purpose: Large promotional feature cards, each with a photo, heading, short copy and a CTA button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cell 1 = image (optional), cell 2 = heading, paragraph(s) and a CTA link (pinned to the card bottom).

## Supported variations

No variations.
