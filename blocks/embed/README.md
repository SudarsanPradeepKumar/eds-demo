# embed

Custom **embed** block. Purpose: Embedded third-party content (e.g. store-locator map) with an optional side panel holding a heading, eyebrow text and a postcode search.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; content cell (heading, text, optional search link whose URL ends in an empty query parameter, e.g. /locations?postcode=, link title = input placeholder) and an embed cell containing only the embed URL (map, YouTube, Vimeo, Twitter/X or any iframe-able URL; optional picture = click-to-load placeholder).

## Supported variations

No variations.
